Create a PUBLIC GitHub repository named hustlecity-game. Extract this ZIP, then upload the CONTENTS (not the ZIP) to the repository root. The .github/workflows/deploy.yml file must be included; GitHub browser upload may hide dotfolders on Windows. Set Settings > Pages > Source to GitHub Actions. GitHub Actions builds the game with npm install and npm run build. This build has not been verified in a browser. The original Playground SDK is emulated locally and some features may need adjustments.
